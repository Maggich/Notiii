# Frontend — React + TypeScript + Vite

Для запуска всей локальной системы из корня проекта:

```powershell
docker compose up --build
```

Открой <http://localhost:5173>. Vite передаёт `/api/*` в Django через внутреннюю сеть Docker. Стартовая страница показывает типизированный асинхронный запрос: загрузку, успех, ошибку, повтор и отмену устаревшего запроса.

Если работаешь с frontend без Docker, в этой папке выполни `npm ci`, затем `npm run dev`. Vite ожидает backend на `http://127.0.0.1:8000`; переменная `BACKEND_URL` задаёт другой адрес.

Доступные команды:

| Команда | Действие |
|---|---|
| `npm run dev` | Сервер разработки |
| `npm run build` | Проверка TypeScript и сборка |
| `npm run lint` | Проверка кода через oxlint |
| `npm run preview` | Локальный просмотр собранной версии |

Зависимости в `node_modules` восстанавливаются из `package-lock.json` командой `npm ci`; `dist` создаётся сборкой. Хранить эти каталоги в папке проекта не нужно.

Изменения интерфейса выполняй только по своему файлу `students/<имя>/Task.md`. Не придумывай API-поля: дождись подтверждённого примера JSON.
