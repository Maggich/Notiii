# Music Sheet Library — контекст проекта

**Состояние на 12.10.2026:** стартовый шаблон создан; функции каталога ещё планируются. Сведения о Jira ниже относятся к последней записанной проверке и в ходе этого перевода заново не проверялись.

## Цель продукта

Публичное веб-приложение для музыкальной школы: просмотр каталога нот, поиск по названию и композитору, фильтры по инструменту, жанру и сложности, страница произведения и просмотр PDF в браузере. Скачивание доступно только при наличии разрешения на распространение.

Аккаунты учеников, публичная регистрация, домашние задания и управление ролями не входят в текущий объём без отдельного решения преподавателя.

## Стартовый шаблон

Преподаватель выбрал Django для backend, React + TypeScript + Vite для frontend и Docker. Каркас находится в `backend/`, `frontend/` и корневом `docker-compose.yml`. PostgreSQL включён как локальная база разработки. До создания каркаса в этой папке не было приложения и Git-метаданных. PDF.js, тестовые библиотеки, настройки размещения, модели и endpoints каталога пока не выбраны или не реализованы.

Файлы, предназначенные для изменения студентами, предварительно созданы с TODO-комментариями. Они являются заготовками, не готовыми функциями. Модели, API-контракт и экран каталога остаются нереализованными до нужных согласований.

Назначение роли не доказывает уровень знаний или назначения в Jira. Начальная диагностика студентов ещё не проведена.

## Решения, которые ещё нужны

Перед реализацией каталога преподаватель согласует поля, права на просмотр и скачивание PDF, правила поиска, формат ошибок и владельцев frontend-файлов. См. [журнал решений](DECISIONS.md). Первые конкретные действия студентов находятся только в их `Task.md`.

- В `Notiii` есть стартовый каркас. Функции каталога не реализованы. Преподаватель передаёт эту основную папку студентам целиком; при последней проверке Git-метаданных не было.

- Подключённый аккаунт ранее был проверен как руководитель `SDT` с доступом к изменению проекта и созданию задач. Права на администрирование настроек проекта отдельно не подтверждались.
