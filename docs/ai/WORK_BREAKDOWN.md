# Декомпозиция работ и соответствие Jira

**Проект Jira:** [Student Development Team (SDT)](https://dzangievmagamet.atlassian.net/plugins/servlet/project-config/SDT/details). 19.10.2026 проект найден по имени и доступным проектам; в нём оставлены прежние 31 задачи без создания дубликатов. Названия и описания обновлены на русском, в формате «зачем → шаги → готово, когда → блокер». Все задачи остались в статусе «К выполнению». Изменение существующей задачи проверено успешно; права администратора настроек проекта и возможность создания новых задач отдельно не проверялись.
