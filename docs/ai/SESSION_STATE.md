# Текущее состояние проекта

Обновлено: 19.10.2026.

## Что есть

- Django + React/TypeScript/Vite + PostgreSQL + Docker Compose.
- Django health endpoint `/api/v1/health/` и стартовая React-страница.
- Основная папка проекта — `Notiii`. Git-метаданных в ней нет. Преподаватель передаёт студентам папку целиком; текущая работа выполняется непосредственно в ней, каждый меняет назначенные файлы.
- Создано пять подробных заданий: `students/Madiar/Task.md`, `students/Arys/Task.md`, `students/Khalil/Task.md`, `students/Adelya/Task.md`, `students/Kirill/Task.md`.
- Созданы пустые стартовые файлы с TODO и владельцами для работ Мадиара, Арыса, Халила и Адели; каждый студент должен менять существующий файл своей роли, а не создавать копию.
- Задания оформлены как пошаговые чек-листы. `[ ]` — не начато, `[-]` — делаю или жду (нужно записать блокер), `[x]` — выполнил, проверил и показал преподавателю. Галочки есть у каждого отдельного шага.

## Чего пока нет

- Таблиц каталога, моделей произведений/композиторов и их миграций.
- Endpoint списка, поиска и интерфейса каталога.
- PDF-функций и утверждённого API/модели каталога.
- Подтверждённых аккаунтов студентов для назначения Jira-задач.
- Подтверждённой преподавателем схемы и API-контракта: TODO-заготовки намеренно не реализуют эти функции.
- Подтверждённого запуска Docker Engine: `docker compose config --quiet` прошёл, но `docker compose ps` вернул отказ доступа к `dockerDesktopLinuxEngine`.

## Порядок начала

1. Преподаватель открывает `ИНСТРУКЦИЯ_ПРЕПОДАВАТЕЛЮ.md`.
2. Перед запуском моделей и API преподаватель записывает решение по полям/первому API в `DECISIONS.md`.
3. Каждый студент открывает только свой `Task.md` и работает только в перечисленных там файлах.
4. Тесты, сборка, Docker и Jira считаются выполненными только после фактической проверки.
